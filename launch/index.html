Clover sandbox launch

This page is a placeholder for the manual wpos5 OAuth prototype. On the Windows machine running the probe:

  1. Run clover_probe oauth-start APP_ID https://achan471.github.io/wpos5-clover-sandbox/callback/ oauth.session, replacing APP_ID with your sandbox app ID.
  2. Open the Authorize URL printed by the probe and approve access for your test merchant.
  3. Copy the full URL shown on the callback page into clover_probe oauth-finish oauth.session.

This page does not start OAuth automatically. A finished Clover app must implement that behavior before using Merchant Dashboard or App Market launch.
